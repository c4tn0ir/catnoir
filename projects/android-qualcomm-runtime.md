# Android / Qualcomm Runtime Research

Sanitized public engineering note.

## Focus

- Qualcomm QNN-related runtime components
- HTP / Hexagon-related components
- OEM AI services and packages
- native libraries and ABI relationships
- JNI/native boundaries
- APK / DEX / Smali inspection
- runtime/performance behavior

## Workflow

- inventory packages, services, processes, libraries, binaries, and model candidates
- map relationships by ownership, dependencies, naming, architecture, and runtime usage
- compare what exists on disk with what is actually loaded/running
- use the runtime map to choose meaningful profiling targets

## Technologies

Android · Linux · C/C++ · JNI · APK/DEX/Smali · ABI/runtime debugging · Python automation · performance profiling
